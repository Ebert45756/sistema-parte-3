
## Sobre o projeto

O Sistema de Aviso Escolar é uma proposta de sistema desenvolvido para facilitar a comunicação entre a escola, professores e alunos. A plataforma terá como objetivo reunir os principais avisos da instituição em um único local, permitindo que as informações sejam divulgadas de forma organizada e acessível.

## Objetivo

O objetivo do projeto é desenvolver uma solução que facilite a divulgação e o acesso aos avisos escolares, evitando que informações importantes sejam perdidas ou fiquem espalhadas em diferentes meios de comunicação.

## Funcionalidades

*- Cadastro de avisos escolares;
- Visualização dos avisos publicados;
- Organização dos avisos por categoria;
- Pesquisa de avisos;
- Identificação da data de publicação;
- Exclusão de avisos quando necessário.*

## Público-alvo

O sistema será destinado principalmente a:

- Alunos;
- Professores;
- Funcionários da instituição.

## Tecnologias

As tecnologias utilizadas no desenvolvimento do sistema serão definidas durante as próximas etapas do projeto, de acordo com as necessidades da aplicação.

## Benefícios

O sistema poderá facilitar a comunicação dentro da instituição, tornando os avisos mais organizados e permitindo que os alunos tenham acesso às informações importantes de maneira rápida e simples.

## Próximas etapas

Nas próximas etapas serão desenvolvidas a interface do sistema, as funcionalidades previstas e, posteriormente, os recursos necessários para o armazenamento e gerenciamento dos avisos.
