
## Sobre o projeto

O Sistema de Aviso Escolar é uma proposta de sistema desenvolvido para facilitar a comunicação entre a escola, professores e alunos. A plataforma terá como objetivo reunir os principais avisos da instituição em um único local, permitindo que as informações sejam divulgadas de forma organizada e acessível.

## Objetivo

O objetivo do projeto é desenvolver uma solução que facilite a divulgação e o acesso aos avisos escolares, evitando que informações importantes sejam perdidas ou fiquem espalhadas em diferentes meios de comunicação.

## Funcionalidades

*- Cadastro de avisos escolares;
- Visualização dos avisos publicados;
- Organização dos avisos por categoria;
- Pesquisa de avisos;
- Identificação da data de publicação;
- Exclusão de avisos quando necessário.*

## Público-alvo

O sistema será destinado principalmente a:

- Alunos;
- Professores;
- Funcionários da instituição.

## Tecnologias

As tecnologias utilizadas no desenvolvimento do sistema serão definidas durante as próximas etapas do projeto, de acordo com as necessidades da aplicação.

## Benefícios

O sistema poderá facilitar a comunicação dentro da instituição, tornando os avisos mais organizados e permitindo que os alunos tenham acesso às informações importantes de maneira rápida e simples.

## Próximas etapas

Nas próximas etapas serão desenvolvidas a interface do sistema, as funcionalidades previstas e, posteriormente, os recursos necessários para o armazenamento e gerenciamento dos avisos.


## Proposta

O projeto consiste no desenvolvimento de um site de avisos escolares, criado com o objetivo de facilitar a comunicação e a divulgação de informações importantes no ambiente escolar. A proposta é oferecer uma plataforma simples, organizada e intuitiva, permitindo que os usuários tenham acesso aos avisos de maneira rápida e clara. O projeto também busca melhorar a organização das informações e proporcionar uma experiência de navegação prática para os usuários.

## Como executar o projeto

O projeto foi desenvolvido utilizando HTML, CSS e JavaScript, não sendo necessário instalar dependências específicas para sua execução. Para utilizar o site, basta baixar ou clonar o repositório do projeto e abrir o arquivo index.html em um navegador de internet. Durante o desenvolvimento, também pode ser utilizado o recurso Live Server, disponível no Visual Studio Code, para executar o site localmente e visualizar as alterações realizadas nos arquivos em tempo real.

## Funcionalidades finais

Ao final do desenvolvimento, o site apresenta uma interface destinada à divulgação e organização de avisos escolares. As principais funcionalidades incluem a exibição dos comunicados, organização das informações na página, elementos interativos desenvolvidos com JavaScript e uma interface visual estruturada com CSS. O site também foi desenvolvido buscando proporcionar uma navegação simples e uma boa visualização dos conteúdos em diferentes tamanhos de tela.

## Validação e testes

Para verificar o funcionamento correto do projeto, foram realizados testes durante as etapas de desenvolvimento e após a conclusão do site. Foram verificadas a estrutura dos elementos em HTML, a aplicação dos estilos em CSS e o funcionamento das funcionalidades implementadas em JavaScript. Também foram realizados testes de navegação, visualização dos avisos e comportamento da página em diferentes tamanhos de tela. Durante esse processo, foram identificados e corrigidos possíveis erros de código e problemas de organização ou apresentação da interface.

## O que foi obtido no final

Ao final do projeto, foi obtido um site funcional para a divulgação de avisos escolares, apresentando uma interface organizada e de fácil utilização. O desenvolvimento permitiu aplicar conhecimentos de HTML, CSS e JavaScript na criação de uma aplicação web, além de proporcionar experiência nas etapas de planejamento, desenvolvimento, testes e correção de problemas. Dessa forma, o projeto atingiu a proposta inicial de criar uma ferramenta digital para facilitar a apresentação e o acesso aos avisos escolares.
