# Documento de Requisitos — Sistema de Aviso Escolar

# Introdução

O Sistema de Aviso Escolar será desenvolvido com o propósito de melhorar a comunicação entre a instituição de ensino, professores e alunos. O sistema permitirá que avisos sejam cadastrados, organizados e visualizados em um único ambiente.

# Objetivo

Desenvolver um sistema que facilite a publicação e o acesso aos avisos escolares, proporcionando uma forma mais organizada e eficiente de transmitir informações aos alunos e demais usuários.

# Público-alvo

O sistema será destinado a:

- Alunos;
- Professores;
- Funcionários da escola.

# Requisitos Funcionais

# — Cadastrar aviso

O sistema deverá permitir que um usuário autorizado cadastre novos avisos escolares

#— Visualizar avisos

O sistema deverá permitir que os usuários visualizem os avisos publicados.

# — Editar aviso

O sistema deverá permitir que um usuário autorizado altere as informações de um aviso cadastrado.

# — Excluir aviso

O sistema deverá permitir que um usuário autorizado exclua um aviso quando necessário.

# — Pesquisar avisos

O sistema deverá permitir que os usuários pesquisem avisos cadastrados.

# — Categorizar avisos

O sistema deverá permitir que os avisos sejam organizados por categorias ou assuntos.

# — Informar data

Cada aviso deverá apresentar sua respectiva data de publicação.

# Requisitos Não Funcionais

# — Usabilidade

O sistema deverá possuir uma interface simples, clara e fácil de utilizar.

# — Compatibilidade

O sistema deverá funcionar em navegadores modernos.

# — Responsividade

O sistema deverá apresentar uma interface adequada para computadores, tablets e celulares.

# — Organização

Os arquivos e códigos do projeto deverão ser organizados de maneira clara e padronizada.

# — Desempenho

O sistema deverá apresentar os avisos de maneira rápida, sem carregamentos desnecessários.

# Escopo do projeto

O projeto terá como foco o cadastro, organização, pesquisa, edição, exclusão e visualização de avisos escolares.

# Possíveis melhorias futuras

- Sistema de login;
- Área exclusiva para professores;
- Notificações de novos avisos;
- Filtros por turma;
- Filtros por disciplina;
- Banco de dados;
- Histórico de avisos;
- Sistema de permissões para diferentes usuários.

# Critérios de aceitação

O sistema será considerado funcional quando for possível cadastrar um aviso, visualizar as informações cadastradas, pesquisar avisos e realizar alterações ou exclusões por usuários autorizados.
